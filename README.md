# ai-finance-moyu — A股摸鱼悬浮窗

挂在桌面上的极简 A股行情小窗。透明无边框、置顶、不占任务栏、不进 Alt+Tab，一键秒隐。

Tauri v2（Rust + WebView2），常驻内存约 **38 MB**，安装包约 5 MB。

## 三种布局

`Ctrl+Alt+1 / 2 / 3` 切换，右键菜单也可切换。

| 布局 | 内容 | 窗口尺寸 |
|---|---|---|
| **数字条** | 每行 `600000 浦发银行 9.69 +2.26%`，无背景，只有文字带描边 | 300 × (行数×26+8) |
| **迷你图** | 名称 + 大字价格 + 分时曲线 | 320 × 170 |
| **列表** | 自选股列表（含浮盈）+ 选中标的的分时图 | 340 × 430 |

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Alt+H` | 显示 / 隐藏（老板键，窗口隐藏时依然生效） |
| `Ctrl+Alt+1` | 切到数字条 |
| `Ctrl+Alt+2` | 切到迷你图 |
| `Ctrl+Alt+3` | 切到列表 |

> **为什么是 `Ctrl+Alt` 而不是 `Ctrl+Shift`**：中文 Windows 上 `Ctrl+Shift` 是输入法切换组合键，
> `Ctrl+Shift+1/2/3` 通常还绑定着切换输入法本身 —— 用它们会在切布局的同时把输入法也切掉。

快捷键写在配置文件里，可随时改，无需重新编译。

## 交互

- **拖动**：按住窗口任意位置拖动
- **右键**：切换布局 / 调透明度 / 立即刷新 / 编辑自选股 / 退出
- **列表布局**：点某一行看它的分时图；迷你图布局点击切换下一只
- 窗口位置与尺寸会记住

### 代码前缀规则

裸 6 位数字按首位推断市场，但**同号不同市场无法区分**，所以建议始终带前缀：

| 输入 | 解析为 |
|---|---|
| `600000` / `688981` | `sh`（沪市主板 / 科创板） |
| `000001` | `sz` → **平安银行**（不是上证指数！） |
| `300750` / `399006` | `sz`（创业板 / 指数） |
| `830799` | `bj`（北交所） |

`sh000001` 是上证指数，`sz000001` 是平安银行 —— 两个都报 `000001`，裸写会解析成后者。

## 行情数据

数据源是腾讯的公开接口，无需登录、无需 Key：

| 用途 | 接口 | 频率 |
|---|---|---|
| 实时报价（整张自选股 **一次请求**） | `qt.gtimg.cn/q=sh600000,sz300750,...` | 3s |
| 分时序列（每只一个请求） | `web.ifzq.gtimg.cn/appstock/app/minute/query?code=sh600000` | 30s |

非交易时段**完全不请求**；若接口返回的日期不是今天（节假日），自动降频重试。

### 三个必须知道的坑（都已处理）

1. **响应是 GB18030 不是 UTF-8** —— 用 `res.text()` 会把「浦发银行」变成乱码，必须用 `encoding_rs` 解码。
2. **报价里的代码字段不带市场前缀** —— `sh000001` 和 `sz000001` 都返回 `000001`，只能靠响应变量名 `v_sh000001` 区分。
3. **均价线要自己算** —— 接口只给累计成交量/成交额，`均价 = 累计成交额 / (累计成交量 × 100)`；接口自带的 `mx_price` 字段是空的。

### 不用东方财富

`push2his.eastmoney.com` 在本机不可用：DNS 正常、TCP 443 可连，但 HTTPS 响应被截断
（`The response ended prematurely`），走代理和直连都一样，备用主机 `push2` / `82.push2his` / `push2delay` 也全部失败。
腾讯接口稳定可用，因此以东财为备选而非主力。

### 代理

取数用的 HTTP client 显式 `.no_proxy()`。本机 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` 指向
`127.0.0.1:7890`，`reqwest` 默认会读取它们，把国内行情请求塞进代理隧道 —— 直连才稳。

## 分时图的 A股惯例

通用图表库不满足这些，所以 `src/chart.ts` 手写 canvas：

- **红涨绿跌**（与欧美相反）
- **X 轴 240 格等距，午休不留空档** —— 11:30 直接接 13:00
- **Y 轴以昨收为中轴对称** —— 昨收线正好在正中，左右刻度对称
- **双 Y 轴** —— 左价格、右百分比
- **均价线**（黄）+ **昨收虚线** + 价格线与昨收之间的半透明填充
- 成本线（青点划线）超出 Y 轴范围时**吸附到边缘加箭头**，不会把当日曲线压平

## 测试

```bash
cd src-tauri
cargo test                    # 41 个单元测试（解析器 / 代码前缀 / 交易时段 / 穿越检测）
cargo test -- --ignored --nocapture   # 4 个联网测试，打真实接口
```

联网测试会真实请求腾讯接口，断言中文名解码正确、`sh000001`/`sz000001` 不混淆、
分时点数在 1..241 且时间戳递增、均价偏离在合理范围、未知代码软失败不 panic。

## 调试

透明窗口出问题时最难排查（失败时屏幕上**什么都没有**）：

- 前端启动失败会显示红色错误浮层（`index.html` 里的内联脚本，模块加载失败也能显示）
- 开发模式下每次渲染会通过 `frontend_log` 命令把布局、行情条数、canvas 实际尺寸写进终端日志
- canvas 上记录了 `dataset.geom` / `dataset.points`，可在 devtools 里直接看

```
  lib.rs                   窗口、快捷键、命令、Alt+Tab 隐藏

  crossing.rs              边沿触发的阈值穿越检测

  tray.rs                  托盘
```
