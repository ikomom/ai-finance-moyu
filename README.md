## ✨ 核心特性一览

### 1. 🎛️ 五大显示形态，随心切换
支持通过全局热键 `Ctrl+Alt+1 ~ 5` 或右键菜单随时切换形态，窗口位置与各形态独立尺寸自动记忆：

| 形态 | 核心内容 | 适用场景 |
| :--- | :--- | :--- |
| **💊 数字条 (Bar)** | 单行 32px 胶囊条，滚轮横向滑动切换标的，文字柔和描边 | 极度隐蔽，与状态栏或桌面边缘浑然一体 |
| **📈 迷你图 (Mini)** | 独立大卡片、融合竞价的分时走势、日K系统、十字光标、标的药丸切歌 | 专注盯单只核心龙头或持仓标的日内/日K走势 |
| **📋 列表看板 (List)** | 高密度自选股票池、全标的实时走势 Sparkline、浮盈汇总统计 | 兼顾多只自选股走势，盈亏与波段一览无遗 |
| **🧭 大盘全景 (Market)** | 三大指数快照、全市场涨跌分布多空温度计、两市总成交额及环比放缩量、领涨板块与龙头 | 宏观大盘温度监控与市场风格定位 |
| **🌐 全球股指 (Global)** | 纳斯达克、标普500、道琼斯、恒生、日经225、韩国KOSPI、富时100 的实时快照与分时走势 | 隔夜外盘与亚太联动观察 |

### 2. ⚖️ 集合竞价全流程深度融入分时 (早盘 09:15-09:25 & 尾盘 14:57-15:00)
全面对齐主流行情软件标准，告别孤立隔绝的静态竞价界面：
- **全谱时间轴贯通（255 Slots）与自适应切换**：
  - **早盘竞价（09:15-09:25）**：3秒高精 Tick 采样，呈现撮合价变动轨迹，09:25 开盘撮合平滑延伸至连续交易；
  - **尾盘竞价（14:57-15:00）**：不可撤单撮合锁定，无缝贯通至最终收盘价；
  - **无竞价数据自适应回退**：若标的未录制早盘竞价，分时图自动呈现标准的 `09:30-15:00`（240 Slots），平滑饱满，无空白悬空。
- **专业级双层堆叠量柱**：
  - 下层**实心灰色柱**（已撮合意向匹配量）；
  - 上层**彩色堆叠柱**（未匹配委托单量：买多红柱、卖多绿柱）；
  - 全副图统一开方非线性缩放，与连续交易时段量柱比例自然衔接。
- **主力意向 Heuristic 智能诊断**：
  - 🚨 **冲高大撤单诱多 (Bull Trap)**：9:15~9:19 虚假挂单抬高试盘价，临近 9:20 撤单跳水；
  - ⚠️ **恐吓大撤单诱空 (Bear Trap)**：早期大单砸盘恐吓抢跑，9:20 前撤单拉升；
  - 🚀 **真实抢筹 (Snatching)**：9:20 后不可撤单阶段，价格坚决推升且撮合量持续放大；
  - 📉 **真实抛压 (Dumping)**：开盘试盘坚决低开，抛盘沉重。
- **本地高精缓存持久化**：竞价 Tick 序列自动落盘至 `%APPDATA%/.../cache.json`，盘后随时开机复盘多空博弈。

### 3. 🕯️ 分时与日K双模系统，指标一键切换
- **走势形态自由切换**：底栏一键切换「分时」与「日K」；
- **日K与均线系统**：包含完整的日K蜡烛线、MA5 / MA10 / MA20 均线系统与持仓成本线；
- **副图双指标随心切**：副图支持一键在 **VOL 成交量** 与 **MACD 指标**（DIF、DEA、MACD 柱）之间无缝切换。

---

### 4. 🚨 智能实时盘口异动与突破告警
内置边沿触发（Schmitt Trigger）防抖检测引擎，精准捕捉盘口瞬时异动：
- **🚀 急涨急跌**：短线 1~2 分钟涨跌速超过 ±1.5% 实时提醒；
- **📈 日内极值突破**：突破日内新高（突破门槛 ≥ 0.8%）或跌破日内新低；
- **💥 盘口大单扫盘/砸盘**：1 分钟脉冲爆量超过日内均速 3 倍且伴随买卖推升；
- **🔴 接近涨跌停与炸板**：封板瞬间或封板后开板异动捕捉，尾盘集合竞价自动防虚警；
- **🎯 成本线与自定义压力/支撑线**：支持设置多条价格预警线，穿越时柔和闪烁边框或弹出系统气泡通知；
- **通知防轰炸原则**：集合竞价阶段自动静默桌面系统弹窗，异动仅在卡片内以状态微标呈现。

---

### 5. 🧠 本地走势研判引擎 (Trend Engine)
基于纯本地 Rust 算法对分时序列进行多维度数学建模，不依赖外部付费投顾服务：
- **均线偏离度与加权均价 (VWAP)**：个股对标日内成交量加权均价，大盘指数对标动态 MA20 趋势；
- **量价顶/底背离识别**：检测双峰价格创日内新高但成交量显著衰竭的背离形态；
- **开盘15分钟区间突破 (ORB)**：自动计算首 15 分钟高低点并标注突破形态。

## 🚀 快速上手

### 下载预编译版本
前往 [Releases 页面](../../releases) 获取由 GitHub Actions 自动编译发布的最新双端安装包：
- 🪟 **Windows 用户**：下载 `.exe`（NSIS 一键安装包）或 `.msi` 安装包运行即可。
- 🍎 **macOS 用户**：下载 Universal 通用版 `.dmg`（内置 Apple Silicon M 系列芯片与 Intel x86_64 架构），将图标拖入 `Applications` 目录即可。

### 从源码构建与开发

#### 前置依赖
1. 安装 [Node.js](https://nodejs.org/) (`>= 18.0.0`)
2. 安装 [Rust 工具链](https://rustup.rs/)（本项目通过 `rust-toolchain.toml` 锁定版本 `1.93.1`）
3. 安装 Visual Studio 2022 C++ 构建工具（包含 MSVC 与 Windows SDK）

#### 启动开发环境
```bash
# 1. 克隆仓库
git clone https://github.com/your-username/ai-finance-moyu.git
cd ai-finance-moyu

# 2. 安装前端依赖
npm install

# 3. 启动本地联调（Tauri 原生桌面窗口 + 前端热重载）
npm run tauri dev
```

#### 在纯浏览器中调试 UI
```bash
# 启动 Vite 前端开发服务器（内置模拟数据，无需编译 Rust，无需开市）
npm run dev
# 浏览器打开 http://localhost:1420/?layout=mini (或 bar / list / market)
```

#### 生产打包构建
```bash
npm run tauri build
```
编译产物位于 `src-tauri/target/release/ai-finance-moyu.exe`，安装包位于 `bundle/nsis/`。

├── src-tauri/                     # Rust 后端高性能引擎 (Tauri v2)

│   │   ├── quote/                 # 腾讯/新浪行情多路并发拉取与 GB18030 解析
│   │   ├── poller/                # 分层自适应行情轮询调度器 (分时/行情/缓存落盘)
│   │   ├── logger/                # 滚动文件持久化与内存环形日志系统
│   │   ├── config/                # 配置原子写盘、恢复备份与 QuotesCache 持久化
│   │   ├── window/                # Win32 API 样式注入 (TOOLWINDOW / 无边框 / 磁吸贴边)

├── src/                           # 现代响应式前端 (SolidJS + TypeScript)
│   ├── chart/                     # 原生 Canvas 高性能渲染引擎
│   │   ├── renderers/             # 分时主图、双层量柱、MACD、Sparkline 子渲染器

│   │   └── canvasUtils.ts         # 高 DPI 画布适配、十字准星与辅助标线
│   ├── components/                # 视图组件 (K线画布、状态栏、底栏分时/日K切换)
│   ├── layouts/                   # 五大形态布局 (Bar, Mini, List, Market, Global)
│   ├── SettingsApp.tsx            # 现代化设置管理面板 (自选股、外观、按键系统、运行日志)
│   └── store.ts                   # 前端全局响应式状态与 Tauri 事件联动
