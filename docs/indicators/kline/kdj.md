## 1. 业务定位与看盘指引

### 1.1 业务定义与核心意图
- **定义**：KDJ 随机指标（Stochastic Oscillator）由乔治·莱恩（George Lane）创立，是金融量化技术分析中最为经典且敏感的短中周期摆动动量指标。本项目采用 A 股市场最通用的日线经典参数组合 $(9, 3, 3)$，即 9 日未成熟随机值 RSV，K 平滑周期 3，D 平滑周期 3。
- **看盘痛点与价值**：
  - **极窄桌面悬浮视窗空间限制**：在桌面常驻、防窥摸鱼的紧凑微型挂件模式下，屏幕像素预算极度受限（主窗口通常仅 200~300px 宽度）。传统证券软件在副图强行挤占 3 根反复缠绕的摆动折线（K 线、D 线、J 线），不仅极易造成严重视觉噪点，而且用户难以在 3 秒之内快速提取有效操盘结论。
  - **纯后台静默计算设计**：本项目确立了**“副图纯净、后台静默递推”**的工程原则。副图完全留给直观的成交量柱状图（VOL）或 MACD，KDJ 曲线不在前端 Canvas 上绘制折线，而是由 Rust 后端收口进行高精度递归运算，提炼出高信息熵的决策微标与气泡清单。
  - **3 秒瞬时战术决断**：通过对 J 线超买钝化（$J > 100$）、极度超卖（$J < 10$）以及低位金叉/高位死叉的精准捕捉，为趋势跟踪（MA 均线系统）提供左侧动量预警，帮助交易者在极小视觉成本下识别日线级别的冲高诱多回落风险与地板恐慌反弹机会。

### 1.2 关键信号解读
- **区间基准界定**：
  - 常规摆动区间：$K, D$ 理论受控于 $[0, 100]$，中轴平衡位为 $50.0$。$20 \sim 80$ 为常态震荡区，$> 80$ 进入超买区，$< 20$ 进入超卖区。
  - J 线灵敏放大：$J = 3K - 2D = K + 2(K - D)$ 作为领先灵敏线，波动范围经常突破 $0 \sim 100$ 的上下界，是识别极端行情超买超卖与均值回归的核心传感器。
- **看多 / 买点信号**：
  - **低位金叉（`低位金叉`）**：在低位区域（尤其是 $K, D < 30$），当前日线 $K$ 线上穿 $D$ 线（$K > D$），且前一日处于 $second\_last\_k \le second\_last\_d$。表明下跌动能衰竭，短期多头量价意愿占优，是重要的波段企稳或右侧买点信号。
  - **日线超卖极值（`日线超卖 J<10` 或 $J < 0$）**：J 线跌破 10 甚至进入负值区域（极度超卖钝化），表明短线空头抛盘极度宣泄，恐慌杀跌盘出清，随时可能孕育技术性超跌反抽或均值回归反弹。
  - **超跌反弹战术共振（结合 AI 决策引擎）**：当“日线 KDJ 超卖（$J < 10$ 或 $J < 0$）”与“分时极度负偏离（$vwapBias < -1.8\%$）”以及“盘口主力大单被动承接（主动买盘占比 $\ge 54\%$ 或买卖失衡度 $\ge +12\%$）”同时发生时，系统触发高置信度“超跌反弹 / 酝酿反抽”战术模型，提示禁止盲目割肉。
- **看空 / 卖点信号**：
  - **高位死叉（`高位死叉`）**：在高位区域（尤其是 $K, D > 70$），当前日线 $K$ 线下穿 $D$ 线（$K < D$），且前一日处于 $second\_last\_k \ge second\_last\_d$。表明短线上攻动能受阻，主力资金分歧加大，是典型的波段见顶防守信号。
  - **日线严重超买（`日线超买 J>100`）**：J 线冲破 100 警戒水位，表明短线买盘过度拥挤亢奋，获利盘丰厚，随时面临剧烈冲高回落或主力洗盘风险。
  - **多头滞涨告警（结合均线系统）**：即便个股均线呈典型多头排列（$MA_5 > MA_{10} > MA_{20}$ 且 $Close \ge MA_5$），若同时侦测到 $J > 100.0$，系统操盘战术强行覆盖为“逢高止盈”，发出“日线多头但短线 J>100 严重超买，谨防冲高回落”的预警，杜绝用户在情绪高潮期盲目追高。
- **中性 / 警示信号**：
  - **J 线极端钝化**：在主升浪连板妖股或极端单边雪崩行情中，J 线可能连续多日贴近 100 顶轨或 0 底轨发生钝化。系统规则明确：**钝化阶段严禁单凭 J 线逆势抓顶摸底**，必须结合生命线 MA20 与盘口筹码承接进行综合研判。
  - **常态中枢收敛**：当 $10 \le J \le 100$ 且未出现交叉突破时，前端以原生等宽数值显示 `K:xx D:xx J:xx`，表征个股处于健康整理或顺势运行区间。

## 2. 数学公式与算法细节

### 2.1 依赖基础数据
- **时序输入**：前复权日 K 线历史序列（Daily Candlestick Bar Series）。
- **单根 Bar 必备字段**：
  - 最高价 $High$ ($H$)，浮点数 `f64`；
  - 最低价 $Low$ ($L$)，浮点数 `f64`；
  - 收盘价 $Close$ ($C$)，浮点数 `f64`。
- **配置参数**：
  - 周期窗口 $N = 9$；
  - K 值平滑因子 $M_1 = 3$（对应加权系数 $1/3$ 与平滑系数 $2/3$）；
  - D 值平滑因子 $M_2 = 3$（对应加权系数 $1/3$ 与平滑系数 $2/3$）。

### 2.2 核心数学公式与递推逻辑

#### 1. 9 日滚动极值查找 (Rolling Extreme Lookup)
对于第 $i$ 根 K 线（$i \in [0, n-1]$），其有效滑动窗口起始索引为：
$$start = \max(0, i - 8)$$
在窗口切片 $k \in [start, i]$ 内查找 9 日最低价 $L_9$ 与最高价 $H_9$：
$$L_9(i) = \min_{start \le k \le i} Low_k$$
$$H_9(i) = \max_{start \le k \le i} High_k$$

#### 2. 未成熟随机值 RSV (Raw Stochastic Value) 计算
衡量当前收盘价在过去 9 日价格波动极差范围内的相对位置：
$$RSV_i = \begin{cases} 
50.0, & \text{若 } |H_9(i) - L_9(i)| < 10^{-6} \\
\operatorname{clamp}\left(\frac{Close_i - L_9(i)}{H_9(i) - L_9(i)} \times 100.0, \, 0.0, \, 100.0\right), & \text{其他}
\end{cases}$$

> **除零与极差坍缩保护**：当价格出现无振幅一字线、停牌或一字涨跌停导致 $H_9 - L_9 \approx 0$ 时，传统公式将发生除以零崩溃（产生 `NaN` 或 `+Infinity`）。系统自动赋基准中轴值 $50.0$，并通过 `.clamp(0.0, 100.0)` 阻断一切浮点畸变。

#### 3. K 值与 D 值平滑递归公式 (Exponential Smoothing Recursion)
采用乔治·莱恩标准平滑加权递推：
- **初始条件（冷启动初值）**：
  $$K_{-1} = 50.0, \quad D_{-1} = 50.0$$
- **逐日递推**：
  $$K_i = \frac{2}{3} K_{i-1} + \frac{1}{3} RSV_i$$
  $$D_i = \frac{2}{3} D_{i-1} + \frac{1}{3} K_i$$

#### 4. J 值动量加速公式
$$J_i = 3 K_i - 2 D_i = D_i + 3(K_i - D_i)$$
> **量化数学意义**：J 值本质是 D 线加上 3 倍的 $(K - D)$ 乖离差。当短期走势快速上攻时，$K$ 线上行速度快于 $D$ 线，$(K - D) > 0$ 被 3 倍杠杆放大，推动 $J$ 线迅速突破 100；反之急跌时 $J$ 线迅速下穿 0 甚至呈现负数。

#### 5. 数值精度与状态保留规则
- **内部迭代无损精度**：在循环内部，`prev_k` 与 `prev_d` 严格保留双精度 `f64` 原生值迭代，杜绝每一轮四舍五入引发的累积截断漂移。
- **输出一位小数舍入**：存入 `KLineBar` 时统一使用单精度一位小数四舍五入：
  $$\text{round\_1}(x) = \frac{\lfloor x \times 10.0 + 0.5 \rfloor}{10.0}$$
- **次末根状态快照**：当处理至倒数第二根 Bar（$i + 1 == n$）时，系统显式锁定 `second_last_k` 与 `second_last_d`，供最终形态研判比较金叉与死叉。

### 2.3 边界情况与冷启动处理
- **历史 K 线样本不足 9 根（$i < 8$）**：
  - 启动阶段不填充 `None` 或 `0.0`，而是采用**动态前缀窗口机制**：$start = 0$，窗口长度为 $i + 1$。
  - 结合 $K_0=50.0, D_0=50.0$ 的中性基准初值，新股上市前 8 个交易日仍能计算出平滑贴合的 KDJ 轨迹，完美契合零白屏准则。
- **空时序序列（`bars.len() == 0`）**：
  - 直接安全输出默认 `KLineData`，`kdj_status` 设为 `None`，杜绝数组越界与 Panic。

## 3. 数据契约与时段规则

### 3.1 上游数据链路
- **数据源主备通道**：
  - **首选通道**：腾讯证券 CDN 前复权日 K 接口（`http://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={code},day,,,320,qfq`）；
  - **备用通道**：新浪证券日 K 接口（`https://quotes.sina.cn/cn/api/json_p.php/var%20_{code}_240/KC_MarketDataService.getKLineData?symbol={code}&scale=240`）；
  - **本地离线容灾**：本地 SQLite 历史时序缓存与平滑基准数据（Baseline Fallback Cache）。
- **计算职责收口**：
  - **Rust 后端唯一收口**：`src-tauri/src/quote/indicators.rs` 中的 `compute_kline_indicators` 承载全量 KDJ 运算与形态判定，随前复权日 K 数据统一吐出给前端。
  - **前端轻量镜像**：`src/utils/indicators.ts` 仅作为前端单元测试、无后端离线模拟和开发环境基准镜像使用，运行时由后端驱动。
- **时序刷新机制**：
  - 盘中实时交易时段以 30 秒至 60 秒为间隔轮询增量计算，将当日即时价格作为最新一根 Bar 的 Close 参与试算；
  - 盘后（15:00 之后）冻结固化收盘快照，开启持久化缓存。

### 3.2 A 股交易时段门禁
- **各时段准入规则**：
  - `09:15 - 09:25`（早盘竞价）：尚未形成今日收盘价，指标锁定展示**昨日收盘日 K 快照**，避免虚假撤单剧烈扰动日线级别研判。
  - `09:25 - 09:30`（盘前静默）：撮合产生今日开盘价，以开盘价作为临时 Close 注入第 $n$ 根 Bar 参与试算，辅助盘前推演。
  - `09:30 - 11:30` / `13:00 - 14:57`（连续竞价）：随着最新报价轮询动态刷新当前 Bar，实时计算最新 $RSV$ 与 $K, D, J$。
  - `14:57 - 15:00`（尾盘集合竞价）：撮合成交锁定，生成全日确定性日 K 线与终局 KDJ 状态。
  - `15:00 之后 / 周末`：后端静默休眠，保持最后一份收盘快照永久有效直至下一个交易日。
- **熔断与断网降级**：
  - 当触发 429 限流或网络阻断时，系统自动切入基准缓存，继续提供历史 KDJ 评估，界面不卡死、不白屏。

## 4. 告警阈值与防扰规范

### 4.1 触发判定规则
在 `src-tauri/src/quote/indicators.rs` 的 `kdj_status` 诊断合成器中，按如下严格优先级判定状态：

```text
[最新 Bar KDJ 状态综合判定流]
  ├── 1. J > 100.0                       => "日线超买 J>100" (tone: warn, action: 逢高止盈)
  ├── 2. J < 10.0                        => "日线超卖 J<10"  (tone: neutral, action: 谨防杀跌)
  ├── 3. K > D 且 second_last_k <= second_last_d => "低位金叉"
  ├── 4. K < D 且 second_last_k >= second_last_d => "高位死叉"
  └── 5. 其他常规态                      => "K:{:.0} D:{:.0} J:{:.0}"
```

#### 均线系统与 KDJ 联合防御规则
1. **多头过热防御**：当均线系统处于多头排列（`bull_aligned`: $MA_5 > MA_{10} > MA_{20}$ 且 $C \ge MA_5$）时：
   - 若 $J > 100.0$：强制将操盘基调置为 `warn`，操盘动作升级为 **“逢高止盈”**，输出诊断文案：  
     *“日线多头但短线 J>{:.0} 严重超买，谨防冲高回落”*。
2. **空头地板防恐慌防御**：当均线系统处于空头排列（`bear_aligned`: $MA_5 < MA_{10} < MA_{20}$ 且 $C \le MA_5$）时：
   - 若 $J < 10.0$：强制将操盘基调置为 `neutral`，操盘动作转为 **“谨防杀跌”**，输出诊断文案：  
     *“空头承压但日线 J<{:.0} 极度超卖，严防地板盲目杀跌”*。

### 4.2 节流防轰炸与静音机制
- **桌面弹窗绝对静音红线**：
  - 严格遵循 `AGENTS.md` §3 及 §7：KDJ 摆动指标属于辅助动量指标，**严禁推送任何 Windows 原生桌面系统通知弹窗或高频蜂鸣声**。
  - 所有异动仅在挂件微标 `KLineBadge` 内部通过图标形态与色彩切换呈现，确保办公摸鱼环境下的绝对低调与零干扰。
- **日志留痕规范**：
  - 日志级别使用标准 `log::info!(target: "ALERT", ...)`；
  - 状态未发生跨越式跃迁（如持续维持超买）时，禁止在每次轮询中无节制输出日志，严格限制高频无序 I/O。
