# 大盘分时黄白双线与剪刀差指标规范 (Index Double Lines & Spread)

## 1. 业务定位与看盘指引
在 A 股看盘传统体系（同花顺、通达信等）中，大盘指数（如上证指数、深证成指、创业板指等）的分时图采用经典的**黄白双线**呈现：
* **白线（加权指数走势线）**：按股票总流通市值加权计算的官方大盘指数点位，受银行、两桶油、贵州茅台等**巨无霸大盘蓝筹股**的影响权重极高。
* **黄线（不加权等权均价线 / 领先指标线）**：不考虑成分股总市值大小，全市场个股的算术平均涨跌幅折算点位，真实反映**广大中小市值题材个股**的赚钱效应。

### 看盘实战口诀与剪刀差状态：
1. **黄上白下（剪刀差 $> +0.3\%$）**：中小盘题材股大幅领跑大盘蓝筹，全市场赚钱效应好，指引**「轻指数、重个股」**。
2. **白上黄下（剪刀差 $< -0.3\%$）**：大盘蓝筹权重股拉抬护盘，但底层多数题材失血下挫，指引**「二八分化、谨防诱多」**。
3. **双线共振（$|\text{剪刀差}| \le 0.3\%$）**：权重与中小盘齐头并进，合力放量普涨或恐慌普跌。
4. **极值喇叭口（$|\text{剪刀差}| \ge 1.0\%$）**：盘面出现极端严重分化。

## 2. 数学公式与算法细节
1. **白线实时点位**：
   $$P_{\text{white}, t} = \text{官方指数实时点位}$$
2. **全市场等权平均涨跌幅** $\bar{R}_t$：
   * 优先基于已拉取的 80 个全行业板块算术平均值及全市场涨跌比估算：
     $$\bar{R}_t = \frac{1}{K}\sum_{k=1}^K \text{SectorPct}_k$$
3. **黄线实时点位（等权折算法）**：
   $$\text{Yellow}_t = \text{PreClose} \times \left(1 + \bar{R}_t\right)$$
4. **多指数差异化独立等权推导**：
   * **上证指数 (000001)**：等权线反映沪市及全市场普罗中小盘算术平均；
   * **创业板指 (399006)**：等权线反映创业板 1300+ 科技成长中小盘股平均涨跌幅，叠加成长题材弹性因子，与权重蓝筹（宁德时代、汇川等）区分，杜绝黄白线重合；
   * **深证成指 (399001)**：反映深市主板与中小创综合等权水平。
5. **分时零轴「多空红绿动能柱」算法**：
   * 附着于主图 $0.00\%$ 昨收平衡虚线：
   * 当 $\text{Yellow}_t \ge P_{\text{white}, t}$（多头题材占优）时，自零轴向上绘制半透明红色微型柱；
   * 当 $\text{Yellow}_t < P_{\text{white}, t}$（权重护盘空头失血）时，自零轴向下绘制半透明绿色微型柱；
   * 柱高按即时剪刀差归一化缩放，透明度固定为 $0.35$，保证不遮挡价格曲线。
6. **黄白线剪刀差 (Scissors Spread)**：
   $$\text{Spread}_t = \left(\frac{\text{Yellow}_t - \text{PreClose}}{\text{PreClose}} - \frac{P_{\text{white}, t} - \text{PreClose}}{\text{PreClose}}\right) \times 100\%$$
   * $\text{Spread}_t > 0$ 表示黄线领先（中小盘强于权重）；
   * $\text{Spread}_t < 0$ 表示白线领先（权重强于中小盘）。

## 3. 数据契约与时段规则
* **适用标的**：所有指数代码（以 `sh000`, `sz399`, `bj899` 开头）。普通个股保持原有的“现价折线 + VWAP 成交均价线”。
* **时段规则**：
  * 集合竞价时段（09:15-09:30）：静默不计算剪刀差；
  * 连续交易时段（09:30-15:00）：实时动态绘制双线与剪刀差；
  * 盘后收盘：固定呈现全天终盘双线形态与收盘剪刀差。

---

## 4. 告警阈值与防扰规范
* **防抖节流**：剪刀差计算随分时 Tick 节流刷新，严禁高频跳动；
* **暗浅色主题自适应**：
  * 暗色模式：白线 `#f8fafc`，黄线 `#eab308`；
  * 浅色模式：加权深灰实线 `#334155`，黄线高对比度琥珀金 `#d97706`；
  * 严禁在浅色模式出现白底白字或反差不足。

---

## 5. 验收基准与测试对齐
* **测试用例 1**：80 个行业全红且中小盘暴涨时，断言 $\text{Spread} > 0$，状态判定为 `黄上白下`；
* **测试用例 2**：上证微涨但全市场个股下挫时，断言 $\text{Spread} < 0$，状态判定为 `白上黄下`；
* **测试用例 3**：指数分时图悬浮光标（Hover）正确外露等权点位与剪刀差百分比；
* **测试用例 4**：代码文件严格遵守单文件 300 行上限。
